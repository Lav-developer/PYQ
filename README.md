# DSMNRU PYQ Archive

[![Netlify Status](https://api.netlify.com/api/v1/badges/your-badge-id/deploy-status)](https://dsmnru-pyq.netlify.app)

A modern, open-source archive for **Dr. Shakuntala Misra National Rehabilitation University (DSMNRU)** previous year question papers (PYQs). Easily browse, preview, and download question papers for B.Tech, B.Sc, and other courses.

🌐 **Official Website:** [https://dsmnru-pyq.netlify.app](https://dsmnru-pyq.netlify.app)

---

## Features

- 🔍 **Search**: Instantly search question papers by course, subject, or year.
- 📄 **Preview**: View PDFs directly in your browser before downloading.
- ⬇️ **Download**: Download question papers with one click.
- 📤 **Contribute**: Upload your own PYQs via our Telegram bot.
- 📱 **Share**: Share papers via WhatsApp, Telegram, or Email.
- 📰 **Newsletter**: Subscribe to get notified about new uploads.
- 🎨 **Modern UI**: Clean, responsive, and accessible design.

## Getting Started

### 1. Clone the Repository

```sh
git clone https://github.com/your-username/dsmnru-pyq.git
cd dsmnru-pyq
```

### 2. Project Structure

```
.
├── data.json                # List of all available PYQs
├── files/                   # PDF files organized by course/semester
├── index.html               # Main website page
├── script.js                # Frontend logic (JS)
├── styles.css               # Custom styles
├── sitemap.xml              # Sitemap for SEO
├── robots.txt               # Robots file for crawlers
└── README.md                # This file
```

### 3. Running Locally

Just open `index.html` in your browser. No build step required.

For local development with a server (to avoid CORS issues):

```sh
npx serve .
# or
python -m http.server
```

Then visit [http://localhost:5000](http://localhost:5000) (or the port shown).

## How to Contribute

### Add New Question Papers

1. **Via Telegram Bot:**  
   Send your PDF to [@dsmnru_bot](https://t.me/dsmnru_bot) with course/year/semester in the caption.

2. **Manual Upload (for contributors):**
   - Place your PDF in the appropriate folder under `files/`.
   - Add an entry in `data.json` with the title and file path.

### Improve the Website

- Fork this repo, make your changes, and submit a pull request.
- Suggestions for UI/UX, bug fixes, or new features are welcome!
