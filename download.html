Installation instructions

  1. Download the APK using the button above — the file is saved to your device's Downloads folder.
  2. Open the APK file from your Downloads app or file manager (tap the "Downloads" notification or open Files).
  3. Allow installation if Android asks: "Install unknown apps" / "Allow from this source". Because this app is distributed directly (not through the Play Store), Android may require you to approve the browser or file manager as an allowed source.
  4. Review the permissions and tap Install.
  5. Open the app when installation completes.

Note: clicking "Download APK" only starts a file download — it does not install the app. Installation happens only after you open the downloaded file and confirm it in Android's installer screen.

Trust & safety

The DSMNRU PYQ APK is built directly from the project source published in this GitHub repository Lav-developer/PYQ. We distribute the file ourselves so students always have a current copy; it is not listed on Google Play.

  • Only download the APK from this page or the linked GitHub Release — we cannot vouch for copies hosted elsewhere.
  • Android may show an "unknown sources" warning for any directly installed app; that is normal for this distribution method, not a sign of a problem in our build.
  • Install updates only from the same source (or this page) so the app can update in place.

Release status

This page is configured with version 1.4.0 (build 11), Android requirement Android 7.0 (API 24) or newer, and reads its download URL from the centralized apk-config.js file. The Android GitHub Actions workflow currently publishes the release APK as a build artifact only — a stable GitHub Release link is added on the android-app branch. Until that link exists, the Download button intentionally stays disabled here rather than pointing at a non-existent file. No file will download from this page until the release link is configured.
